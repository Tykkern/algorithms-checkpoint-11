# Контрольная точка 11: динамическое программирование

Практикум по алгоритмам. Шесть задач, решения на Java.

| № | Задача | Класс | Подход | Время | Память |
|---|---|---|---|---|---|
| 1 | Путь робота по платформам | `PlatformJumps` | ДП по позиции | O(n) | O(1) |
| 2 | Рюкзак без повторов | `Knapsack` | ДП по массе, массы сверху вниз | O(n·W) | O(W) |
| 3 | Наибольшая общая подпоследовательность | `CommonSubsequence` | ДП по префиксам, две строки таблицы | O(\|s\|·\|t\|) | O(\|t\|) |
| 4 | Грузы на массу ровно C | `ExactCargo` | неограниченный рюкзак, пара (прибыль, количество) | O(n·C) | O(C) |
| 5 | Число наибольших возрастающих подпоследовательностей | `IncreasingSubsequences` | сжатие значений + дерево Фенвика | O(n log n) | O(n) |
| 6 | Кратчайшая общая надпоследовательность | `ShortestSupersequence` | ДП по суффиксам + жадная сборка | O(\|s\|·\|t\|) | O(\|s\|·\|t\|) |

## Запуск

Нужен JDK 17 или новее, Gradle скачается сам через wrapper.

```
gradlew test                          # тесты
gradlew run -q --args="2" < input.txt # задача 2, ввод из файла
```

Номер задачи передаётся аргументом, входные данные читаются из stdin в формате
из задания, ответ печатается в stdout. Например, для задачи 4:

```
2 6
2 2
3 3
```

ответ `6 2`: прибыль 6 дают и три груза массы 2, и два груза массы 3, выбирается
вариант с меньшим числом грузов.

На Windows проект лучше держать в папке без кириллицы в пути. Иначе Gradle
не находит тестовые классы (`ClassNotFoundException`), хотя они скомпилированы.

## 1. Путь робота по платформам

`cost[i]` - минимальная стоимость дойти до платформы `i`. На неё приходят
с `i - 1` или с `i - 2`:

```
cost[i] = min(cost[i - 1] + |h[i] - h[i - 1]|, cost[i - 2] + |h[i] - h[i - 2]|)
```

Нужны только два последних значения, поэтому массив не хранится. Разность высот
доходит до 2 * 10^9 и в `int` не помещается, всё считается в `long`.

## 2. Рюкзак без повторов

`best[c]` - максимальная полезность набора из уже рассмотренных предметов
массой не больше `c`. Очередной предмет массы `w` либо не берётся, либо
добавляется к лучшему набору массы `c - w`. Массы перебираются сверху вниз:
тогда `best[c - w]` ещё не содержит текущего предмета, и каждый предмет попадает
в набор не больше одного раза. Таблица `n * W` не нужна, хватает одной строки
на `W + 1` чисел.

## 3. Наибольшая общая подпоследовательность

`lcs[i][j]` - ответ для префиксов длины `i` и `j`. Если их последние символы
равны, они входят в общую строку: `lcs[i - 1][j - 1] + 1`. Иначе один из них
лишний: `max(lcs[i - 1][j], lcs[i][j - 1])`. Строка таблицы зависит только
от предыдущей, поэтому хранятся две строки по `|t| + 1` чисел.

## 4. Грузы на массу ровно C

Для каждой массы `c` хранится лучшая пара (прибыль, количество): больше прибыль,
а при равной прибыли меньше грузов. Масса `c` получается из `c - w[i]`
добавлением груза типа `i`, пара меняется на `(+p[i], +1)`. Такая добавка
не меняет порядок пар, поэтому лучшая пара для `c` строится из лучшей пары
для `c - w[i]`.

Массы перебираются снизу вверх, поэтому `c - w[i]` уже может включать грузы
того же типа, как и нужно при неограниченном количестве. Недостижимые массы
помечены прибылью `-1`, и если масса `C` так и осталась недостижимой, ответ `-1`.

Ответ выводится в одной строке: прибыль и количество через пробел.

## 5. Число наибольших возрастающих подпоследовательностей

Для подпоследовательностей, которые заканчиваются на `a[i]`, нужны лучшая длина
и число способов среди тех, что заканчиваются на строго меньшее значение левее `i`.
Значения сжимаются в ранги, по рангам строится дерево Фенвика, и в каждой ячейке
лежит пара (длина, количество). Запрос на префиксе рангов меньше ранга `a[i]`
даёт лучшую пару, к длине прибавляется 1, и пара записывается на ранг `a[i]`.

Пары объединяются так: большая длина побеждает, при равной длине количества
складываются по модулю 10^9 + 7. Если меньших значений нет, подпоследовательность
начинается с `a[i]`, это один способ.

Квадратное решение «для каждого i перебрать все j < i» на 200 000 элементах
сделало бы 2 * 10^10 шагов.

Ответ выводится в одной строке: длина и количество по модулю через пробел.

## 6. Кратчайшая общая надпоследовательность

`rest[i][j]` - длина кратчайшей строки, содержащей суффиксы `s[i..]` и `t[j..]`.
Если один суффикс пуст, это длина другого. Если `s[i] == t[j]`, символ общий:
`1 + rest[i + 1][j + 1]`. Иначе следующим идёт `s[i]` или `t[j]`:
`1 + min(rest[i + 1][j], rest[i][j + 1])`.

Строка собирается слева направо. Символ, которого нет ни в начале `s[i..]`,
ни в начале `t[j..]`, писать бессмысленно: оставшаяся длина от него не уменьшится.
Значит, кандидатов не больше двух, `s[i]` и `t[j]`, и каждый ведёт в своё
состояние. Из кандидатов, сохраняющих минимальную длину, берётся меньший символ:
все варианты одной длины, и порядок решает первый отличающийся символ.

## Тесты

- на каждую задачу примеры, граничные случаи и сверка с перебором на случайных
  входах (перебор путей, подмножеств, количеств грузов и всех строк по порядку);
- входы максимального размера из ограничений с таймаутом 5 секунд, в том числе
  ответы больше `int` и число подпоследовательностей 2^100000 по модулю;
- `MainTest` проверяет чтение ввода и формат вывода для всех шести задач.
